01. Greeting Program

Accepts a user's name through an HTML form and displays a personalized greeting.

Source Code
Greeting.php 
<!DOCTYPE html>
<html>
<head>
    <title>Greeting Program</title>
</head>
<body>
    <h2>Greeting Program</h2>

    <form method="post">
        Enter your name:
        <input type="text" name="name" required>
        <button type="submit">Submit</button>
    </form>

    <?php
    if ($_SERVER["REQUEST_METHOD"] === "POST") {
        $name = htmlspecialchars($_POST["name"]);
        echo "Hello, " . $name . "! Welcome!";
    }
    ?>
</body>
</html>
Sample Output
Enter your name: Rifqah Hello, Rifqah! Welcome!

02. Palindrome Checker

Checks whether the entered string reads the same forward and backward.

Source Code
Palindrome.php 
<!DOCTYPE html>
<html>
<head>
    <title>Palindrome Checker</title>
</head>
<body>
    <h2>Palindrome Checker</h2>

    <form method="post">
        Enter a string:
        <input type="text" name="word" required>
        <button type="submit">Check</button>
    </form>

    <?php
    if ($_SERVER["REQUEST_METHOD"] === "POST") {
        $word = $_POST["word"];
        $cleanWord = strtolower(trim($word));
        $reversed = strrev($cleanWord);

        if ($cleanWord === $reversed) {
            echo htmlspecialchars($word) .
                " is a palindrome.";
        } else {
            echo htmlspecialchars($word) .
                " is not a palindrome.";
        }
    }
    ?>
</body>
</html>
Sample Output
Enter a string: madam madam is a palindrome.

03. Program Using Function

Demonstrates how to define and call a PHP function to display a greeting.

Source Code
Function.php 
<!DOCTYPE html>
<html>
<head>
    <title>PHP Function</title>
</head>
<body>
    <h2>Greeting Using Function</h2>

    <form method="post">
        Enter your name:
        <input type="text" name="name" required>
        <button type="submit">Submit</button>
    </form>

    <?php
    function greet($name) {
        echo "Hello, " . htmlspecialchars($name) . "!";
    }

    if ($_SERVER["REQUEST_METHOD"] === "POST") {
        greet($_POST["name"]);
    }
    ?>
</body>
</html>
Sample Output
Enter your name: Rifqah Hello, Rifqah!

04. Array Manipulation

Creates an array of fruit names and displays each item using a foreach loop.

Source Code
ArrayManipulation.php 
<!DOCTYPE html>
<html>
<head>
    <title>Array Manipulation</title>
</head>
<body>
    <h2>Array of Fruits</h2>

    <?php
    $fruits = array("Apple", "Mango", "Orange");

    foreach ($fruits as $fruit) {
        echo htmlspecialchars($fruit) . "<br>";
    }
    ?>
</body>
</html>
Sample Output
Apple Mango Orange

05. Personal Information

Collects a person's name, age, and email address and displays the submitted details.

Source Code
PersonalInformation.php 
<!DOCTYPE html>
<html>
<head>
    <title>Personal Information</title>
</head>
<body>
    <h2>Personal Information Form</h2>

    <form method="post">
        Name:
        <input type="text" name="name" required>
        <br><br>

        Age:
        <input type="number" name="age" min="1" required>
        <br><br>

        Email:
        <input type="email" name="email" required>
        <br><br>

        <button type="submit">Submit</button>
    </form>

    <?php
    if ($_SERVER["REQUEST_METHOD"] === "POST") {
        $name = htmlspecialchars($_POST["name"]);
        $age = htmlspecialchars($_POST["age"]);
        $email = htmlspecialchars($_POST["email"]);

        echo "<h3>Submitted Information</h3>";
        echo "Name: " . $name . "<br>";
        echo "Age: " . $age . "<br>";
        echo "Email: " . $email;
    }
    ?>
</body>
</html>
Sample Output
Name: Rifqah Age: 19 Email: rifqah@example.com
